如何科学上网
2023-07-15 15:27 visibility

前言

工作中发现不少人还不会翻墙，于是想分享一些自己的经验。

目前有两类主流方案：

  1. 自建代理：利用 Cloudflare 免费版搭建，零成本、无限流量、永久可用，推荐首选
  2. 付费机场：购买服务商的订阅，省心省事，适合不想折腾的用户

方案一：Cloudflare 免费自建（推荐）

Cloudflare 提供免费版的 Pages、Workers 和 KV 存储，可以搭建个人专属的代理节点，无需任何费用。

优势

  • 完全免费：Cloudflare 免费版额度足够个人使用
  • 无限流量：没有流量限制
  • 全球节点：自动分配最优节点，也可手动选择
  • 稳定可靠：Cloudflare 是大厂，服务稳定性高
  • 无限复活：即使一个节点失效，可以快速重建

搭建步骤

  1. 注册 Cloudflare 账号：访问 cloudflare.com 免费注册
  2. 创建 Pages 项目：在 Cloudflare 控制台选择 Pages，新建项目
  3. 部署代理脚本：可以通过 GitHub 连接部署开源脚本，推荐使用 Cloudflare-vless-trojan 或 BPB 面板
  4. 配置 KV 存储：在 Workers 中创建 KV 命名空间，绑定到 Pages 项目
  5. 获取订阅链接：部署完成后会生成订阅链接

具体搭建流程可以参考视频教程：2026 最强Cloudflare 免费VPN自建！无限复活、永久可用，讲解非常清晰。

客户端配置

拿到订阅链接后，在客户端中添加订阅即可：

  • Windows: v2rayN
  • Android: V2rayNG
  • iOS: Shadowrocket (App Store 付费购买)
  • macOS: ClashX 或 V2rayU

方案二：付费机场（备选）

如果不想自建，也可以购买付费机场的订阅服务。我用的是 STC，一家位于香港的服务商，按流量计费是 0.8 元每 G，一年有效期。

如需选择其他机场，可参考 机场推荐 或 免费节点

客户端下载

安卓客户端: V2rayNG, Windows客户端: Clash

配置建议查看机场提供的文档。

结尾

建议配置路由规则以节省流量，另一个原因是开启代理后部分国内网站是无法访问的。

好了，如有任何疑问，欢迎评论或通过 email 联系我。
